DKK EMILX — PROTOTIPE WEBSITE

Isi:
- index.html
- style.css
- app.js
- logo-dkk-emilx.png (logo biru neon tanpa username/password)

CARA MENJALANKAN:
1. Ekstrak ZIP.
2. Buka index.html di browser untuk melihat pratinjau.
3. Login saat ini hanya simulasi tampilan, bukan autentikasi sungguhan.

PENTING SEBELUM ONLINE:
- Jangan masukkan password asli ke HTML atau JavaScript.
- Login dan role User/Admin/Developer harus diverifikasi di backend.
- Panel Developer pada prototipe ini hanya placeholder, bukan panel produksi yang aman.
- User hanya melihat prediksi; tidak ada tombol tambah/edit/hapus untuk User.
- Data prediksi pada prototipe ini hanya berada di browser, bukan database bersama.
- Prediksi adalah simulasi statistik pertandingan Free Fire, bukan taruhan uang.

DEPLOY:
1. Upload isi folder ini (bukan file ZIP) ke root repository GitHub.
2. Import repository di Vercel.
3. Pilih Framework Preset: Other; build command dapat dikosongkan untuk situs statis.
4. Deploy.
